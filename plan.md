A simulation with the user's measured inference times (100 x 5 min, JACK in/out) gave: 1024 -> 162 ms buffered, ~33 tiny underruns/hour; **960 -> 144 ms, ~10/hour**; 480 -> 155 ms, ~19/hour. To try: `PIPEWIRE_QUANTUM=960/48000 ./run.sh` (the whole PipeWire graph runs at the lowest quantum any client requests), then compare the Log page's "Output underruns" lines and an Audacity measurement. If it holds up, set it in `run.sh` or offer it as a setting.
